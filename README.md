# Брендбук Nextera

Единый источник дизайн-кода Nextera для людей и агентов: цвета, шрифт, логотипы, шаблоны.

- **Мастер — Figma** [TOLK_NEXTERA](https://www.figma.com/design/eJKQuooNI4IBcZsXrLQ5yi/TOLK_NEXTERA--Copy-?node-id=711-1249), страница `guide`. Дизайнеры правят там.
- **Это репо — выгрузка из Figma**: файлы, которыми пользуются сайты, документы и агенты. Значения здесь руками не меняют — сначала Figma, потом выгрузка.
- **Агенты платформы** получают брендбук навыком `nextera-brand` (папка `skill/`), а не чтением этого репо.

## Главные правила

1. **Не копируйте значения цветов в код.** Подключайте `tokens/tokens.css` (или читайте `tokens/colors.json`). Зашитый цвет — такой же хардкод, как зашитый адрес сервера.
2. **Шрифт — только IBM Plex Sans** (400/500/600). IBM Plex Mono — только для кода и данных. Halvar — шрифт логотипа, в текстах не используется.
3. **Палитра 75 / 25:** три четверти — нейтральные (`ink`, `brown`, `sand`, `stone`, `paper`), четверть — акцент.
4. **Правило зелёного:**
   - `#4DE41D` — только заливки, маркеры, точки, рамки;
   - зелёный **текст** на светлом фоне — `#2A7D10` (у `#4DE41D` на светлом контраст 1.46:1, текст не читается);
   - на тёмном фоне текст может быть `#4DE41D`.
5. **Зелёного мало.** Один акцент на экран или слайд. Вторичные акценты — тёмно-коричневый `#726658`.
6. **Не делаем:** надписи капсом над заголовками, карточки «✕ / ✓» розовым и зелёным, градиентный текст, полосы сбоку у скруглённых блоков, моноширинный шрифт «для технологичности».

## Что внутри

| Папка | Что |
|---|---|
| `tokens/` | `colors.json`, `typography.json`, `tokens.css` — значения с ролями |
| `logo/` | Логотип nextera (тёмный/светлый), монограмма «n», логотип с символом |
| `avatars/telegram/` | Пять вариантов аватара канала, 1024×1024 |
| `templates/word/` | Бланк Word: шапка с логотипом и реквизитами ООО «Некстера» (`letterhead.py` собирает `nextera-letterhead.docx`) |
| `skill/nextera-brand/` | Навык для агентов платформы |
| `scripts/` | Выгрузка из Figma (появится вместе с токеном Figma) |
